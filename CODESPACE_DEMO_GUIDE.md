### 🛠️ Troubleshooting for Testers

If something doesn't work:

**Servers not starting:**
```bash
./start-demo.sh
```

**Ports not showing:**
- Look for the "Ports" tab in VS Code
- Manually forward ports 3000 and 3001

**AI not responding:**
- Check backend terminal for errors
- Verify health check at port 3001
